# Fortune Cookie Game

## Description
  A simple game that print a random messages in your screen.

## How to play
1. Run the `FortuneCookie` program.
2. The game will display a message on your screen, then the program will ask you to play again or not.
3. If you picked y or Y the program will display another message for you.
4. If you picked n or N the program will display exit message then end it self.
**Note:** If you entered any charcter without n or y the program will not accept it.
