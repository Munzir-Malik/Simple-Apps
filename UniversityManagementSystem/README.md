# University Management System

## Overview

This project is a simple University Management System, It simulates the basic functionality of managing students, courses, and departments. The system demonstrates object-oriented programming concepts like encapsulation, constructors, and methods.

## Features

1. Student Management: Add students with details such as name, ID, and department.
2. Course Management: Add courses with details like course name, code, and department.
3. Department Details: Display a department's name, head, students, and courses.


## How to Use

- Copy the code into an IDE or any complier can run Java programs (e.g., IntelliJ IDEA or VSC).

- Compile and run the program to see the output and interact with the program.

- You can edit the main method to see different outputs and another test cases that you feel free with.
