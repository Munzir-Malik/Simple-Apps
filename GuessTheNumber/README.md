# Guess The Number Game

## Description

"Guess The Number" is a simple console-based game where the player has to guess a randomly generated number between 1 - 10. The player has three attempts to guess the correct number. If the player guesses the number correctly within the given attempts, they win. Otherwise, they lose.

## How to Play

1. Run the `GuessTheNumber` program.
2. The game will prompt you to guess a number between 1 and 10.
3. Enter your guess and press Enter.
4. The game will inform you if your guess is correct or not.
5. If your guess is incorrect, the game will provide a hint to guess a smaller or bigger number.
6. You have three attempts to guess the correct number.
7. If you guess the number correctly within three attempts, you win. Otherwise, you lose.
