# ROFLCOPTER

## Description

"ROFLCOPTER" is a simple console-based animation program that continuously prints an ASCII art representation of a helicopter with the text "LOL:ROFL:ROFL".
The program creates an illusion of movement by printing the helicopter in a loop with a short delay between each frame.

**Note:** If your device is not strong enough, the program may lag due 
to the continuous printing and the short delay between frames.

## How It Works

The main logic of the program is implemented in the `main` method of the `Roflcopter` class:

- The program runs an infinite loop that prints the ASCII art of the helicopter.
- The `Thread.sleep(90)` method is used to introduce a delay of 90 milliseconds between each frame, creating the animation effect.
- The program continuously clears the console by printing several blank lines before printing the helicopter again.
